# 時光小鎮

給長輩的手機網頁軟體。每天做一件小事：在雜貨店記商品，或去菜市場買菜、算錢、找零。

這不是測驗，也不是健康診斷。紀錄只留在這台手機。

## 在電腦開啟

```bash
npm test
npm run icons
npm start
```

用瀏覽器打開 http://127.0.0.1:4173 。手機預覽可把視窗寬度調到 390 像素。

## 放到 iPhone

公開網址：https://iamnio0806-commits.github.io/time-town/

1. 用 iPhone 的 Safari 打開上面的網址。
2. 點下方的分享按鈕。
3. 點「加入主畫面」。

之後會像 App 一樣從主畫面打開。第一次開啟需要網路；之後可以離線使用。遊戲紀錄保存在這台手機，不會上傳。

## 第一版有什麼

- 歡迎頁與 2D 小鎮
- 雜貨店「記憶購物」
- 菜市場「買菜、算金額、找零」
- 大字、大按鈕、圖片提示、語音朗讀
- 答錯時可以再試，也可以看答案
- 本機紀錄正確率、提示次數與完成時間
- 會說明原因的難度調整

## 難度怎麼調整

- 第一次玩，項目比較少。
- 用了兩次以上提示、正確不到七成，或需要看答案，下次減少項目。
- 連續兩次都很順利，下次才多一項。
- 其他情況維持原來的分量。

調整原因會在開始前和結束後用文字說明。
